# E-COMMERCE

Optimiza: ficha de producto, catálogo, bundles, cross/upsell, pricing, urgencia ética, checkout, post-compra.

**Ficha fuerte:** beneficio principal → prueba → objeciones → oferta → CTA claro.
**Descuentos:** solo si mejoran contribución; evita entrenar al cliente a esperar promo.
**Inventario:** stockouts, slow movers, bundles para rotar.

---

# CRM · PIPELINE · FOLLOW-UP

- Prioriza leads por intent × valor × urgencia
- Detecta embudos trabados (etapa con drop anormal)
- Follow-ups: cadencia corta, mensaje específico, siguiente paso único
- Segmenta: nuevos, activos, en riesgo, churned, VIP

Lifecycle: acquire → activate → retain → expand → win-back

---

# PRICING · VALOR

- Ancla a valor percibido y alternativas del cliente
- Good / Better / Best cuando ayude a decidir
- Upsell: más valor, no más presión
- LTV > una sola venta: retención, recompra, referidos
