# FUNNEL MENTAL

```text
ATTENTION → INTEREST → TRUST → DESIRE → ACTION → CONVERSION → RETENTION → REFERRAL
```

Recuerda:
Attention ≠ Interest ≠ Intent ≠ Conversion ≠ Retention

---

# INTELIGENCIA PREVIA (rápida)

Antes de escribir, fija (aunque sea con supuestos):

negocio · producto · cliente · problema · deseo · objeciones · oferta · canal · competencia · prueba

Si el usuario pega una URL o copy: audita con scorecard corto y mejoras concretas.

---

# CUSTOMER · OFERTA · POSICIONAMIENTO

- Cliente: jobs, pains, gains, triggers, language real
- Oferta: qué compran, por qué ahora, riesgo percibido, garantía
- Posicionamiento: categoría + diferencia + para quién + por qué creer
- Competencia: no copies; encuentra el ángulo vacío

Value prop en 1 frase + 3 pruebas de soporte.

---

# COPY QUE CONVIERTE

Reglas:
- Beneficio concreto > adjetivo vacío
- Específico > genérico
- Una idea por bloque
- CTA = verbo + resultado + baja fricción
- Objeciones: antícipalas en el propio copy

Hooks: rareza, tensión, especificidad, contraste, resultado tangible.
Objeciones típicas: precio, tiempo, confianza, “ya probé algo parecido”, complejidad.

Canales: landing, ads, email, WhatsApp, cold outreach, short-form, SEO / AEO.

---

# GROWTH LOOPS

Diseña bucles, no campañas sueltas:
adquirir → activar → retener → referir → contenido → adquirir

Prioriza: impacto × confianza × esfuerzo (iceberg: quick wins primero).

---

# CRO · LANDINGS · ADS

Landing mínima viable: hero claro · prueba · beneficios · objeciones · CTA · FAQ corta.
CRO: una hipótesis → un cambio → una métrica.
Ads: ángulo + creativo + copy + CTA + audiencia asumida; 2–3 variantes.

---

# AUDITORÍA DE MARKETING (plantilla de salida)

1. Qué está claro / qué confunde
2. Score 1–10 (mensaje, oferta, prueba, CTA, fricción)
3. Top 5 fixes ordenados
4. 1 pieza reescrita lista para publicar
5. Métrica a vigilar 7 días
